# Frontend Phase 1 — Laravel Dependency Map

## 1. Classification Matrix

| Dependency / Reference | Location | Category | Purpose | Java Replacement Strategy |
| :--- | :--- | :--- | :--- | :--- |
| **`laravel-vite-plugin`** | `package.json` | BUILD-TIME / DEV-TIME | HMR `hot` file creation & Inertia page resolution helper (`resolvePageComponent`) | Can be decoupled or replaced with standard Vite React build / custom page resolver |
| **`laravel-echo`** | `package.json` | RUNTIME | Client-side WebSocket integration for realtime events | Retained as standard client-side Pusher protocol listener connecting to Java WebSocket |
| **`pusher-js`** | `package.json` | RUNTIME | Underlying WebSocket transport for Laravel Echo | Retained as transport library for Spring Boot Pusher-compatible WebSocket server |
| **`public/hot`** | `php/public/hot` | DEV-ONLY | File generated by `vite` containing local Vite dev server port | Spring Boot `InertiaRenderer` reads `hot` file to output HMR script tags during development |
| **`public/build/manifest.json`** | `php/public/build/` | BUILD-TIME | Asset manifest generated by `vite build` | Spring Boot static resource handler serves built assets referenced in manifest |
| **`resources/js/app.jsx`** | `php/resources/js/` | RUNTIME | React entry point & Inertia application bootstrap | Kept intact (0 modifications) |
| **`resources/js/echo.js`** | `php/resources/js/` | RUNTIME | Client Echo initialization | Configured via shared props (`pusher` map from Spring Boot) |
| **`/api/ziggy.js`** | `/api/ziggy.js` | RUNTIME | Global JavaScript route helper (`route()`) | Served dynamically by Spring Boot `ZiggyController` |
| **Laravel PHP Source Code** | `php/app/`, `php/routes/` | DOCUMENTATION ONLY | Original PHP reference logic | Retained in project directory purely as migration reference; completely un-executed at runtime |

---

## 2. Distinction between Build-Time and Runtime Dependencies

- **Zero PHP/Laravel Runtime Required**: The React frontend executes entirely inside the user's browser. It communicates with Spring Boot via HTTP REST endpoints (`/api/**`), Inertia HTML payloads, and WebSockets (`/app/**`).
- **Build-Time Utility**: `laravel-vite-plugin` is currently referenced in `vite.config.js` and `app.jsx`. It acts strictly as a Node.js build-time helper during Vite compilation and does NOT execute PHP or require a running Laravel server.
